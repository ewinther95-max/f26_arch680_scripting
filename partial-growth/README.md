# Partial growth

A website for testing one growth rule. The page frames a model and names what the current settings do to four relationships: relief on the mass, a fold in the ground, a seat, and the arm that leaves.

The field is partial. A budget decides how much of it is allowed to exist. It starts in one place and spends that budget locally. Fine grain is a tight ceramic ripple. Broad grain is a deeper, slower fold. The same fold continues off the wall into the ground and, where a ridge meets grade, thickens to sitting height.

Section moves the arm. Below grade it cuts otherwise flat ground: a short cut is a step, a middle cut is a passage, a long cut is a sunken room with a mouth at the mass. Near grade it is a supported link. Above grade it is a cantilever over intact ground, ending in a thickened lookout.

## Run

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 4327
```

Open [http://localhost:4327](http://localhost:4327).

Click the field to move the nucleation. Budget, grain, and section are the only controls.
